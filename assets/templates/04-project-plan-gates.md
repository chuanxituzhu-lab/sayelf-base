#### 2. 出口门标准

**Gate 1：Discovery → Design**
- [ ] 业务痛点已量化，基线数据已采集
- [ ] AI机会地图已输出，P0场景已确定
- [ ] 业务Owner已签字确认

**Gate 2：Design → Build**
- [ ] 技术方案已评审通过
- [ ] MVP范围已锁定，非核心需求已转入Backlog
- [ ] 数据接入方案已确认可行

**Gate 3：Build → Deploy**
- [ ] 原型已开发完成，功能测试通过
- [ ] 离线评测集通过率>=80%
- [ ] 权限、日志、反馈机制已内置

**Gate 4：Deploy → Optimize**
- [ ] 影子运行>=1周，无重大异常
- [ ] 种子用户（3-5人）已开始使用
- [ ] 监控告警已配置

**Gate 5：Optimize → 结项**
- [ ] 业务指标达到目标值
- [ ] 用户周活跃率>=60%
- [ ] 可复用资产已沉淀（>=2个）
- [ ] 内部负责人已培养，可独立运营
